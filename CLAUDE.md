# CLAUDE.md — Website Portofolio Ivan

Proyek: website portofolio satu halaman (Next.js App Router + TypeScript + Tailwind v4), deploy ke Vercel.

## Cara kerja
- Kerjakan **satu sesi** dari `TASKS.md` per percakapan. Jangan lompat ke sesi berikutnya.
- Baca hanya bagian `REQUIREMENTS.md` yang disebut di sesi itu. Jangan membaca `PRD.md` kecuali diminta.
- Fitur yang tidak tertulis di `REQUIREMENTS.md` tidak dibuat; catat idenya di bagian Catatan `TASKS.md`.
- Semua teks konten ada di `content/data.ts`; komponen tidak berisi teks konten.
- Konten website berbahasa Inggris; komentar dan catatan boleh berbahasa Indonesia.
- Setelah tiap task: pastikan `npm run build` lolos, lalu centang task di `TASKS.md`.
- Desain UI ada di Figma (file key `6UXb3z3AUxcy1shJk6V7sC`). Ambil hanya node section yang sedang dikerjakan (peta node di `PROMPTS.md` §0.3). Hasil Figma = referensi; kelas Tailwind tetap dari `REQUIREMENTS.md` §6.

## Perintah
- `npm run dev` — server lokal
- `npm run build` — wajib lolos sebelum commit
- `npm run lint`
